How it works

Everyone opens this same file in Chrome, Edge or Firefox (not inside WhatsApp's preview). One player opens a table and shares the code; everyone else types that code under Join. Anyone can leave and come back with the same code. Card text and art come from Scryfall.

Make sure everyone has the same version of the file: different versions can't see each other. The top bar shows how many relay servers you're connected to and how many players are seated.

The engine plays the rules for you: triggers, costs, taxes and stax pieces are applied automatically on every player's screen. During a game, Effects in the top bar lists every rule-changing card in play and which ones affect you.

Want to try both seats? Open the file in two browser windows and join your own table.
